# Nhật ký quyết định

Mỗi quyết định quan trọng lưu thành một tệp Markdown riêng: `YYYY-MM-DD-short-name.md`.

Mẫu tối thiểu:

- Context:
- Decision:
- Alternatives considered:
- Evidence:
- Consequences:
- Owner:
- Status:

Chỉ ghi quyết định đã được chủ sở hữu chấp thuận hoặc đã được kiểm chứng bằng test/review. Không dùng nhật ký này để thay thế hồ sơ task.
